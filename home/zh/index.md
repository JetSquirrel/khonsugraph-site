# KhonsuGraph

KhonsuGraph 是基于 HawDB 的本地图数据桌面工作台。使用 Cypher 和 SQL 探索关系，连接数据源，与 AI 一起构建可审阅的仪表盘。

## 一段关于探索的故事

人类探索未知的历史，也是一部追踪线索的历史。

### 远古时代 — 猎人追踪足迹。

在没有地图的荒野中，猎人观察泥土上的脚印、折断的树枝和动物留下的痕迹。

单个足迹无法说明什么。但当足迹彼此连接，便能还原猎物的行动轨迹，推断它的去向。

当足迹彼此连接，方向开始显现。

### 古埃及时期 — 人们仰望月亮。

在古埃及神话中，Khonsu 是月亮、旅行与守护之神。他的名字意为“旅行者”，象征着月亮穿越夜空的旅程。

当太阳落下，月光为黑暗中的旅行者照亮前路。

黑暗并不意味着没有道路， 只是道路尚未被发现。

### 大航海时代 — 探险者追随星辰。

为了寻找香料与通往东方的航路，航海者驶向未知的海洋。

他们观察星辰的位置，结合风向、洋流与航海记录，在浩瀚海面上确定方向。

孤立的星辰只是光点。 当它们被联系起来，便成为指引航程的星图。

### 今天 — 追踪数字世界的痕迹。

今天，威胁猎人追踪数字世界的痕迹。现代世界的黑暗隐藏在海量数据之中。

安全分析师追踪攻击者留下的日志，重建完整的攻击路径。SRE 追踪服务之间的依赖，定位故障根因与影响范围。审计人员追踪交易与实体关系，揭示隐藏的异常和风险。

看似无关的事件、资产与身份， 在关系中逐渐显现出完整的脉络。

从荒野中的足迹，到夜空中的星图，再到数字世界的关系网络， 人类始终在做同一件事： 连接线索，发现真相。

这就是 Khonsu Graph。 一个面向人与 AI 协作的本地图分析工作空间，让复杂的关系变得可见，让隐藏的威胁有迹可循。

Khonsu Graph — Follow the traces. Reveal the unseen.

## KhonsuGraph 是什么？

KhonsuGraph 是免费开源的本地 HawDB 图数据桌面工作台，集成 Cypher 和 PostgreSQL 方言 SQL 查询、图画布、数据源插件和纯文本仪表盘。

## 图数据会离开我的电脑吗？

图数据在本机存储和查询。数据源插件可以访问你配置的系统，例如 AWS。如果使用外部 AI Agent，相关数据处理仍受该 Agent 自身的隐私与数据设置约束。

## 支持哪些系统？

项目提供 Apple 芯片 macOS 和 64 位 Windows 的发布打包流程，可用安装包以 GitHub Releases 为准。Windows 安装包未签名，最近的引擎升级在 macOS 上完成验证。

## 这是 HawDB 官方产品吗？

不是。KhonsuGraph 是基于 HawDB 构建的独立项目，采用 Apache-2.0 协议免费开源。

## 可以运行任意 Cypher 查询吗？

KhonsuGraph 使用 HawDB 支持的 Cypher 语法，与其他图数据库有所不同。支持的语法与当前限制请参阅查询指南。
