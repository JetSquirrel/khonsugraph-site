# KhonsuGraph — 狩人たちのために。

つながりをたどり、証拠にたどり着く。

オープンソースでローカルファーストのグラフ調査ワークベンチ。セキュリティ、インフラストラクチャ、その先の領域まで。HawDB のグラフを Cypher と SQL でたどり、データを接続し、AI エージェントとダッシュボードを組み立てます。

## 探索の物語

未知を探る歴史は、手がかりを追う歴史でもあります。

### 太古の荒野 — 狩人は足跡を追った。

地図のない荒野で、狩人は土に残った足跡、折れた枝、動物が残した痕跡を読み取ります。

ひとつの足跡だけでは、多くは語りません。しかし次の足跡へとつながると、その痕跡は道筋を浮かび上がらせます。動物がどこを通り、どこへ向かうのかがわかります。

足跡をつなぐ。 そこに進むべき方向が見えてくる。

### 古代エジプト — 人々は月を見上げた。

古代エジプト神話で、コンス（Khonsu）は月と旅と守護の神です。その名は「旅人」を意味し、月が夜空を旅する姿を表しています。

日が沈むと、月光は暗闇を行く旅人に道を示します。

暗闇は道がないという意味ではない。 ただ、その道がまだ見えていないだけだ。

### 大航海時代 — 探検家は星を追った。

香辛料と東への航路を求めて、航海者たちは未知の海へ乗り出しました。

星の位置を読み、風向きや海流、航海記録と合わせて、広い海の上で進むべき方角を定めました。

ひとつの星は、ただの光の点にすぎない。 つながった星々は、針路を示す星図になる。

### 現在 — デジタルの痕跡を追う。

今日、脅威ハンターはデジタル世界の痕跡を追います。現代の闇は、膨大なデータの中に隠れています。

セキュリティアナリストはログから攻撃を再構成します。SRE はサービス間の依存をたどり、根本原因と影響範囲を特定します。監査担当者は取引とエンティティの関係を追い、異常とリスクを明らかにします。

無関係に見える出来事、資産、アイデンティティも、 そのつながりの中に物語を現す。

荒野の足跡から夜空の星図へ、そしてデジタル世界の関係ネットワークへ。 私たちはずっと同じことをしてきました。 手がかりをつなぎ、真実を見つける。

それが KhonsuGraph。狩人たちのために。

- **脅威ハンター**: 攻撃経路と脅威を追跡。
- **SRE**: 根本原因と依存関係を追跡。
- **不正調査担当者**: 異常な取引と隠れたつながりを追跡。
- **研究者**: 複雑なネットワークのパターンを探索。

KhonsuGraph — Built for Hunters. 狩人たちのために。

## KhonsuGraph とは？

KhonsuGraph は、ローカルの HawDB グラフのための無料のオープンソースデスクトップワークベンチです。Cypher と PostgreSQL 方言の SQL クエリ、グラフキャンバス、データソースプラグイン、プレーンテキストのダッシュボードを組み合わせています。

## グラフはマシンの外に出ますか？

グラフの保存とクエリはお使いのコンピューター上で行われます。データソースプラグインは、AWS など設定したシステムに接続することがあります。外部の AI エージェントを使う場合は、そのエージェント自身のデータとプライバシー設定が適用されます。

## 対応しているプラットフォームは？

Apple silicon の macOS と 64 ビット Windows 向けのリリースパッケージを用意しています。配布状況は GitHub Releases を確認してください。Windows パッケージは署名されていません。最新のエンジン更新は macOS で検証されました。

## HawDB の公式製品ですか？

いいえ。KhonsuGraph は HawDB を基盤とする独立したプロジェクトです。Apache-2.0 ライセンスで無料かつオープンソースです。

## 任意の Cypher クエリを使えますか？

KhonsuGraph は HawDB がサポートする Cypher 構文を使用しており、他のグラフデータベースとは異なります。対応パターンと現在の制限はクエリガイドを参照してください。
