# KhonsuGraph 문서

KhonsuGraph는 HawDB를 기반으로 구축된, 그래프 조사를 위한 오픈 소스 로컬 우선 데스크톱 워크벤치입니다. 플러그인으로 데이터를 가져오고, Cypher로 관계를 조회하거나 PostgreSQL 방언 SQL로 테이블을 조회하며, 그래프 캔버스에서 경로를 따라가고, 각 레코드의 근거가 되는 증거를 보관한 뒤 그 결과를 대시보드로 만들 수 있습니다.

이 프로젝트는 HawDB 위에 구축된 독립 프로젝트이며 Apache-2.0 라이선스로 배포됩니다.

## 로컬에 남는 것

그래프 저장과 쿼리 실행은 사용자의 컴퓨터에서 이루어집니다. 소스 플러그인은 사용자가 설정한 시스템에 접속합니다. 외부 AI 에이전트는 자체적인 데이터 처리 설정을 가지므로, 쿼리 결과를 공유할 때는 해당 설정을 확인하십시오.

이 가이드는 KhonsuGraph **0.3.0**을 설명하며, 이 버전은 HawDB를 **0.29.0**에 고정합니다. 경로 탐색, 증거, 저장된 조사, 스냅샷, Neo4j 플러그인은 0.3.0에서 추가되었으므로 이전 릴리스에는 없습니다. 설치된 버전은 `khonsu --version`으로 확인하고, [소스 리포지터리](https://github.com/JetSquirrel/KhonsuGraph)를 참고하십시오.
