# KhonsuGraph 문서

KhonsuGraph는 HawDB 그래프를 위한 로컬 우선 데스크톱 워크벤치입니다. 그래프 디렉터리를 열고 스키마를 확인한 뒤, Cypher로 관계를 조회하거나 PostgreSQL 방언 SQL로 테이블을 조회하고, 그 결과를 대시보드로 만들 수 있습니다.

이 프로젝트는 HawDB 위에 구축된 독립 프로젝트이며 Apache-2.0 라이선스로 배포됩니다.

## 로컬에 남는 것

그래프 저장과 쿼리 실행은 사용자의 컴퓨터에서 이루어집니다. 소스 플러그인은 사용자가 설정한 시스템에 접속합니다. 외부 AI 에이전트는 자체적인 데이터 처리 설정을 가지므로, 쿼리 결과를 공유할 때는 해당 설정을 확인하십시오.

현재 소스는 HawDB를 **0.12.0**에 고정하고 있습니다. 이 가이드는 해당 체크아웃을 설명하며, 설치된 릴리스의 동작은 다를 수 있습니다. [소스 리포지터리](https://github.com/JetSquirrel/KhonsuGraph)를 참고하십시오.
