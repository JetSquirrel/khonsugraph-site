# Documentation de KhonsuGraph

KhonsuGraph est un atelier de bureau local-first pour les graphes HawDB. Ouvrez un répertoire de graphe, inspectez son schéma, interrogez les relations en Cypher ou les tables en SQL de dialecte PostgreSQL, puis transformez le résultat en tableau de bord.

C'est un projet indépendant construit sur HawDB, publié sous Apache-2.0.

## Ce qui reste local

Le stockage du graphe et l'exécution des requêtes s'effectuent sur votre ordinateur. Les plugins de source contactent les systèmes que vous configurez. Un agent IA externe dispose de ses propres paramètres de traitement des données ; examinez-les lorsque vous partagez des résultats de requête avec lui.

La source actuelle épingle HawDB à **0.12.0**. Ces guides décrivent cette copie de travail ; le comportement des versions installées peut différer. Voir le [dépôt source](https://github.com/JetSquirrel/KhonsuGraph).
