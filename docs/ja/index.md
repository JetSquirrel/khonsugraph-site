# KhonsuGraph ドキュメント

KhonsuGraph は、HawDB グラフのためのローカルファーストのデスクトップワークベンチです。グラフディレクトリを開き、そのスキーマを調べ、Cypher でリレーションシップを、PostgreSQL 方言の SQL でテーブルをクエリし、その結果をダッシュボードに変換できます。

HawDB 上に構築された独立したプロジェクトで、Apache-2.0 の下で公開されています。

## ローカルに留まるもの

グラフの保存とクエリの実行は、あなたのコンピューター上で行われます。ソースプラグインは、あなたが設定したシステムに接続します。外部の AI エージェントには独自のデータ取り扱い設定があります。クエリ結果をそのエージェントと共有する際には、それらの設定を確認してください。

現在のソースは HawDB を **0.12.0** に固定しています。本ガイドはそのチェックアウトを説明したものです。インストール済みリリースの挙動は異なる場合があります。[ソースリポジトリ](https://github.com/JetSquirrel/KhonsuGraph) を参照してください。
