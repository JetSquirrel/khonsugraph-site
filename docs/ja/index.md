# KhonsuGraph ドキュメント

KhonsuGraph は、HawDB 上に構築された、グラフ調査のためのオープンソースのローカルファーストデスクトップワークベンチです。プラグインを通じてデータを取り込み、Cypher でリレーションシップを、PostgreSQL 方言の SQL でテーブルをクエリし、グラフキャンバス上で経路をたどり、各レコードの背後にある証拠を保持し、その結果をダッシュボードに変換できます。

HawDB 上に構築された独立したプロジェクトで、Apache-2.0 の下で公開されています。

## ローカルに留まるもの

グラフの保存とクエリの実行は、あなたのコンピューター上で行われます。ソースプラグインは、あなたが設定したシステムに接続します。外部の AI エージェントには独自のデータ取り扱い設定があります。クエリ結果をそのエージェントと共有する際には、それらの設定を確認してください。

本ガイドは KhonsuGraph **0.3.0** を説明したもので、HawDB を **0.29.0** に固定しています。経路探索、証拠、保存された調査、スナップショット、Neo4j プラグインは 0.3.0 で追加されました。それ以前のリリースにはこれらはありません。`khonsu --version` を実行して、お使いのバージョンを確認してください。[ソースリポジトリ](https://github.com/JetSquirrel/KhonsuGraph) も参照してください。
