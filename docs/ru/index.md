# Документация KhonsuGraph

KhonsuGraph — открытая настольная рабочая среда для графовых расследований, работающая по принципу local-first и построенная на HawDB. Загружайте данные через плагины, выполняйте запросы к связям на Cypher или к таблицам на SQL в диалекте PostgreSQL, прослеживайте пути на графовом холсте, сохраняйте доказательства для каждой записи и превращайте результат в дашборд.

Это независимый проект на основе HawDB, распространяемый под лицензией Apache-2.0.

## Что остаётся локально

Хранилище графа и выполнение запросов работают на вашем компьютере. Плагины источников обращаются к системам, которые вы настроили. Внешний ИИ-агент имеет собственные настройки обработки данных — проверьте их, прежде чем передавать ему результаты запросов.

Эти руководства описывают KhonsuGraph **0.3.0** с закреплённой версией HawDB **0.29.0**. Исследование путей, доказательства, сохранённые расследования, снимки и плагин Neo4j появились в 0.3.0; в более ранних выпусках их нет. Выполните `khonsu --version`, чтобы узнать свою версию, и загляните в [репозиторий с исходным кодом](https://github.com/JetSquirrel/KhonsuGraph).
