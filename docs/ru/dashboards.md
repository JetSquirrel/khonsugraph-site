# Дашборды

Файл `.dash` — это обычный текст: именованные запросы, графики и фильтры. Он читает граф, открытый в приложении в данный момент. Данные импортируются отдельно через плагины; блока `source` нет.

## Первая графовая панель

Пройдя раздел [начало работы](./getting-started), сохраните это в файл `overview.dash`:

```hcl
query "dependencies" {
  cypher = "MATCH (a:Host)-[r:DEPENDS_ON]->(b:Host) RETURN a, r, b"
}

plot "dependencies" {
  type = "graph"
  query = query.dependencies
  caption = name
  width = 12
}
```

```sh
khonsu check overview.dash --db graphs/demo
khonsu open graphs/demo
khonsu open overview.dash
```

`check` выполняет каждый запрос только на чтение, проверяет столбцы графиков и пробует фильтры с реальными значениями. Исправьте все найденные ошибки, прежде чем открывать дашборд или делиться им.

## Графики и компоновка

Типы графиков: `table`, `bar`, `line`, `area`, `scatter`, `pie`, `map`, `card`, `text` и `graph`. `width` задаёт ширину от 1 до 12 столбцов. Графовые запросы возвращают узлы и связи целиком; `caption` выбирает свойство узла, которое показывается как его подпись. `group` позволяет группировать узлы по свойству.

## Общие фильтры

Строка таблицы, столбец диаграммы или узел графа может управлять фильтром. В этом примере табличный запрос возвращает `service`, а другой запрос использует `WHERE $service`:

```hcl
filter "service" {
  plot = plot.services
  column = service
  match = "s.name"
}
```

Плейсхолдер должен быть целым условием `WHERE`, при необходимости соединённым через `AND`. В Cypher выбранное значение сравнивается с выражением `match`; в SQL — с самим столбцом, поэтому `match` не нужен. Невыбранное условие удаляется; исходный график сам себя не фильтрует. Полные [примеры из репозитория](./examples) включают такие связанные запросы и графики.

## Проверка с помощью агента

Оставьте комментарий к графику в приложении. Агент читает комментарии, правит файл, запускает `check` и отвечает. Комментарии хранятся рядом с дашбордом в `FILE.comments.json`. Presence позволяет показать, какие графики редактирует агент, а окно перерисовывается при изменении файла.

```sh
khonsu comments overview.dash
khonsu presence overview.dash --doing editing --plot dependencies
khonsu check overview.dash --db graphs/demo
khonsu presence overview.dash --doing idle
```

В формате нет произвольных функций, условий и стилей, зависящих от данных. Команды для проверки см. в разделе [CLI и ИИ-агенты](./cli).
