# Устранение неполадок

## Команда khonsu не найдена

Нажмите **Command line & AI** (значок робота) в строке заголовка приложения и заново откройте терминал. В macOS можно вызвать исполняемый файл приложения напрямую:

```sh
/Applications/KhonsuGraph.app/Contents/MacOS/khonsugraph --version
```

В Windows оставьте `khonsu.exe` вместе с остальными файлами распакованного пакета и добавьте этот каталог в PATH либо вызывайте файл по полному пути.

## Граф заблокирован

Каталог графа HawDB принадлежит одному процессу. Чтение и проверки дашбордов идут через работающее окно, но для записи и синхронизации источников граф должен быть свободен. Закройте граф в другом процессе. Никогда не удаляйте `khonsugraph.lock`, `owner.hawdb.lock` или файлы базы данных, чтобы обойти блокировку.

## Граф сообщает old_format {#old-format}

В HawDB 0.25 изменился формат хранения, и более старые графы не читаются, поэтому граф, записанный KhonsuGraph 0.2.0 или более ранней версией, не открывается с типом ошибки `old_format`. `khonsu rebuild --db DIR` создаёт его заново из источников данных и сохраняет старый каталог рядом как `DIR.hawdb-old`. Всё, что было записано вручную, а не синхронизировано, не переносится.

## Графовая панель пуста

Возвращайте узлы и связи целиком (`RETURN a, r, b`), а не только имена. Проверьте, что открыт граф, для которого написан дашборд. Выполните `khonsu schema --db DIR` и запустите запрос напрямую, чтобы убедиться в метках и результате.

## Запрос или дашборд завершается ошибкой

Выполните `khonsu check FILE --db DIR` и прочитайте все найденные ошибки. График может ссылаться на отсутствующий столбец; импортированный набор данных может использовать другие метки. Некоторые возможности Cypher не поддерживаются: см. [ограничения запросов](./queries#current-limitations).

Если запрос на чтение превышает свой бюджет, сузьте его с помощью условий и `LIMIT`. Уменьшение только `--max-rows` не снижает стоимость выполнения.

## Источник не синхронизируется

Выполните `khonsu plugin describe ID` и проверьте поля конфигурации. Убедитесь, что плагины из пакета остаются рядом с исполняемым файлом. Пути к отдельным CSV-файлам сохраняются как абсолютные при добавлении источника. Пути внутри JSON в `nodes` и `edges` сохраняются как есть и должны быть абсолютными. Для AWS нужны AWS CLI и доступный настроенный профиль, если не используются фикстуры. Записывайте `regions` как текст через запятую, а не как массив JSON.

Неудачная синхронизация может оставить уже записанные записи. Устраните причину и синхронизируйте снова, чтобы согласовать данные. Проверьте `skipped_edges` на неразрешённые концы связей.

## Сообщить о проблеме

Укажите версию приложения, операционную систему, команду и тип ошибки в [issue на GitHub](https://github.com/JetSquirrel/KhonsuGraph/issues). Удалите из примеров учётные данные и приватные значения графа.
