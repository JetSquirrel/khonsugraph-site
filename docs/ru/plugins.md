# Разработка плагинов

Плагин — это отдельный исполняемый файл, который передаёт узлы и связи через stdin/stdout в формате JSON Lines. Хост записывает записи в HawDB. Плагину не нужно самому открывать граф.

Версия протокола 1 экспериментальна и может измениться до 1.0. [Полное описание протокола](https://github.com/JetSquirrel/KhonsuGraph/blob/main/docs/plugins.md) поддерживается вместе с приложением.

## Состав пакета

```text
folders/
  khonsu-plugin.json
  plugin.py
```

```json
{
  "id": "folders",
  "name": "Folders",
  "version": "0.1.0",
  "protocol": 1,
  "entry": ["python3", "plugin.py"],
  "description": "A folder tree as nodes and CONTAINS relationships",
  "permissions": {"read_files": true, "commands": ["python3"]}
}
```

Исполняемый файл запускается с папкой плагина в качестве текущего каталога. Самый маленький полный пример — [плагин folders на Python](https://github.com/JetSquirrel/KhonsuGraph/tree/main/examples/plugins/folders) в репозитории.

## Операции

| Операция | Вход | Выход |
| --- | --- | --- |
| `describe` | Нет | Схема конфигурации, разрешения и типы вывода |
| `test` | Запрос с конфигурацией и секретами | `test_result` или `error` |
| `sync` | Запрос с конфигурацией, секретами, режимом и курсором | Записи и ход выполнения, затем `done` или `error` |

Каждое сообщение — объект JSON в отдельной строке с полем `type`. Диагностика выводится в stderr. Сохраняйте ID стабильными между синхронизациями; концы связей ссылаются на ID узлов из того же источника. Успешную синхронизацию завершайте сообщением `done`.

## Разрешения и секреты

Объявляйте доступ к сети, чтение файлов и команды в манифесте. KhonsuGraph показывает эти объявления для подтверждения, но **не** изолирует процесс в песочнице. Помечайте секретные поля конфигурации как `secret: true`, чтобы использовать связку ключей системы.

Устанавливайте каталог или ZIP с плагином после проверки:

```sh
khonsu plugin install ./folders --yes
khonsu plugin describe folders
```

`--yes` подтверждает объявленные разрешения. Установщик копирует плагин; после изменения исходного кода установите его заново. Перед реализацией полной или инкрементальной синхронизации см. [семантику синхронизации](./data-sources#sync-semantics).

## Как поделиться плагином {#share}

Чтобы другие могли устанавливать ваш плагин по имени, опубликуйте его в маркетплейсе. См. [публикацию плагина](./marketplace#publish).
