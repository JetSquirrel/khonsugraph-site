# KhonsuGraph website

The bilingual product website and documentation for [KhonsuGraph](https://github.com/JetSquirrel/KhonsuGraph), a local-first HawDB graph workbench. Built following the structure of `ducklocal-site` and `cloudbridge-site`.

| Path | Contents |
| --- | --- |
| `home/` | Static English and Chinese product pages, shared CSS and brand illustrations |
| `scripts/generate-home.mjs` | Homepage template and bilingual copy; generates HTML, Markdown and discovery files |
| `docs/` | Bilingual VitePress documentation, local search and downloadable samples |
| `dist/site/` | Complete production output, generated by the build |
| `wrangler.jsonc` | Cloudflare Workers static-assets configuration |

## Local development

Requires Node.js 22 or newer.

```sh
npm --prefix docs ci
npm run generate
npm run dev               # product pages on http://127.0.0.1:4173
npm run dev:docs          # VitePress development server
```

Edit homepage copy in `scripts/generate-home.mjs`, then run `npm run generate`. Edit brand narrative in `scripts/story-content.mjs` and presentation in `home/styles.css`. Homepage HTML is committed so it can be served directly. The homepage is static and requires no JavaScript.

## Build and preview everything

```sh
npm run build
npm run preview           # http://127.0.0.1:4173, includes /docs/
```

Stop the other server first if port 4173 is occupied, or set `PORT=4174`. The build checks VitePress links, then checks all generated HTML links, anchor targets and local assets. `npm run check` repeats those checks against the existing build.

The pages have no analytics, external fonts or third-party scripts. VitePress search runs locally. The homepage needs no framework or runtime dependencies.

The `hawdb-wasm-demo` project is a design and interaction reference only; the website does not embed or link to its online demo.

`home/assets/exploration-story.png` is the user-supplied four-panel illustration, preserved as the original bitmap. Four SVG viewports display its individual panels in the brand narrative. The page serves `exploration-story.webp`, a quality-90 WebP encoding of the same bitmap (about 180 KB instead of 1.8 MB).

`home/assets/hero-traces.png` is the custom hero illustration generated with the built-in ChatGPT image generation tool. The generation prompt is saved in `artifacts/hero-image-prompt.md`. The page serves `hero-traces.webp` and a 960 px `hero-traces-960.webp` for narrow screens; regenerate them with `cwebp -q 82 -m 6` (add `-resize 960 0` for the small one) after replacing the PNG.

## Deployment

No domain or live deployment is assumed. Set `SITE_URL` to the real HTTPS origin when it is known:

```sh
SITE_URL=https://your-domain.example npm run build
```

This enables canonical URLs, language alternates, sitemaps and absolute discovery links. Without it, the build intentionally omits canonical URLs and sitemaps rather than advertising a made-up domain.

For Cloudflare Workers Builds, use project name `khonsugraph-site` and deploy command `npx wrangler deploy`. The configuration runs `sh scripts/build.sh`, installs the locked docs dependencies, and serves `dist/site`. Set `SITE_URL` in build environment variables. Domain binding is a separate hosting setup step.

Routing follows [Cloudflare's static HTML handling](https://developers.cloudflare.com/workers/static-assets/routing/advanced/html-handling/): document routes resolve without `.html`, directory indexes retain trailing slashes, and unknown routes use a 404 page.

## Content provenance

Product content comes from the app README, CLI reference, plugin protocol, examples and HawDB 0.12.0 upgrade notes. Downloads link to the releases listing without assuming a release asset exists. The logo and `.dash` samples are copied from the application repository. Update documentation when application behavior changes.

Each documentation page is also exported as Markdown; `/llms.txt` points to the combined English and Chinese references. Full docs are available at `/docs/llms-full.txt` and `/docs/zh/llms-full.txt`.
